# Java Lucky Racer Game

A console car-racing game in Java. Five cars race for 10 hours, and each car gets a random speed every hour.

## Features

- Five `AutomaticCar` objects (model and year)
- Each hour, each car gets a random speed from 0 to 299 and adds it to its distance
- Prints a dashed progress bar and the total distance for each car after every hour

## Tech stack

Java

## Getting started

```bash
git clone https://github.com/Matiz009/java-lucky-racer-game.git
cd java-lucky-racer-game
javac LuckyRacer.java AutomaticCar.java
java LuckyRacer
```

## Project structure

```
LuckyRacer.java    Main race loop
AutomaticCar.java  Car class
```
